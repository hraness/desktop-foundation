# Hraness CLI kit

Shared Rust helpers for command-line audience detection, output style, and
macOS permission notices. The default build uses only the standard library.
The optional `clap` feature adds help and usage-error formatting.

The [desktop-foundation repository](https://github.com/hraness/desktop-foundation)
contains the matching TypeScript helpers, permission documentation, and contract
tests. This crate does not install a desktop helper or open a window.
